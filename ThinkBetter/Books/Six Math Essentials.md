### 数字

数字是一种有用的工具，但我们必须认识到它们何时适用，何时不适用。

虽然每个数字本身都是有限的，但数字集合整体上却是无限的。
%%<  无穷大是一个好用的工具 %%


人们自然会好奇无穷大是否算作一个数。标准的数系——包括自然数（计数数）、整数（自然数及其负数，加上零）、有理数（所有整数和分数）以及实数（数轴上的所有数，包括像π和An expression reads: square root of 2.这样的无理数）——并不包含无穷大。但有时，将这些常规数系扩展到包含无穷大会很有用。


%%< 十进制只是一种常用表达%%



正如英国数学家约翰·沃利斯在1657年发明了∞作为无穷大的符号一样；只是恰巧我们现在常用的是十进制。二进制，十六进制在历史上也多有使用。 同样，巴比伦的六十进制也衍生出了我们计时系统中的分钟和秒（以及角度）。古罗马人使用罗马数字系统，这是一种用字母 I、V、X、L、C、D 和 M 分别代表 1、5、10、50、100、500 和 1000 的计数方案。古希腊人则使用希腊字母来表示数字，其中 α 代表 1，β 代表 2，以此类推

**实数实际上并不存在于物理世界中**。我们无法像实数那样进行无限精确的测量。这就是为什么 1.0000… 和 0.9999… 是同一个数字。
	我们常常被迫将连续的事物离散化，这不可避免地会造成一些不自然的过渡。时区就是一个很好的例子。地球自转，以及由此带来的日出日落，是一个连续的现象，但设置连续的时区是不切实际的。我们的时钟会不同步，我们东边二十英里的人总是比我们快一分钟。因此，我们将世界划分为二十四个时区，并设立了国际日期变更线。跨越日期变更线时，物理上并没有什么变化，但星期日突然变成了星期一，反之亦然。地图并不等同于实际的疆域。这些坐标上的奇点是我们选择的表示系统所造成的产物。


存在哪些类型的数字（或数字系统）以及它们是否有用？拥有一个唯一的“真数系统”似乎更简单，但不同类型的数字扮演着不同的角色，并源于不同的现实世界任务。正如我们所见，**整数用于计数离散对象，而实数用于测量连续对象**。


许多数字系统都是出于实际需要而诞生的。十六世纪，意大利博学家吉罗拉莫·卡尔达诺是最早发明一种奇特的新型数字的人之一。这些数字如此不同寻常，以至于一个世纪后，法国数学家兼哲学家勒内·笛卡尔将其斥为“虚数”。卡尔达诺当时试图解形如 ax² + bx + c = 0 的二次方程，但他无法将其分解。他发现，通过引入 -1 的平方根，他可以解出这些方程。他并不完全理解其中的原理，但这种方法确实有效。（要理解虚数的必要性，一个简单的方法是考虑二次方程 x² + 1 = 0。x 是什么？）

随着时间的推移，数学家们逐渐认识到，如果将数的概念扩展到包含负数的平方根，就可以求解更多的方程。-1 的平方根被定义为虚数单位 i，而形如 a + bi（包含实部和虚部）的复数在量子物理学、电子工程和计算机图形学的发展中变得至关重要。


历史上，我们通过拓展“数”的概念不断取得进步。通过研究不同的数系，数学家们发现了离散世界和连续世界之间奇妙的联系；我们可以将自然数视为实数的子集，而实数又是复数的子集。

将数视为一个松散的、相互关联的概念家族。复数被发现后，我们发现它们对于解决各种问题都不可或缺，即使是那些并非直接涉及复数的问题。有时，当你想要解决一个涉及实数的问题时，引入复数作为一种临时的变通方法会很有帮助，它允许你做一些在实数域中无法实现的奇特操作。（国数学家、前总理保罗·潘勒韦在1900年所写：“在实数域的两个真理之间，最简单、最短的路径往往要经过复数域。”）


数学的魅力之一在于它探讨的是理论上的、可能的宇宙，涉及的概念并不一定受限于具体的现实。


如何判断一个新的数系是否值得开发呢？像自然数、整数、有理数、实数和复数这样的标准数系之所以有用，是因为它们遵循一定的规律；

**交换律**指出运算顺序无关紧要：A + B = B + A 且 A × B = B × A。
**结合律**指出运算的组合方式无关紧要：(A + B) + C = A + (B + C) 且 (A × B) × C = A × (B × C)。这些看似简单却功能强大的规则，通过反复运用，帮助我们求解二次方程、三次方程和其他复杂的方程。


明确这些规则提供了一种清晰明确的约束，限制了数字系统的数量。通常，规则比具体的运算方式更为重要。如果你理解了规则允许的范围，就可以将你对基本数字的直觉应用于更高级的数字概念。例如，一些数学对象满足交换律或近似交换律，而另一些则满足结合律或近似结合律。数字是我们的参照点，而数字系统则是捕捉数字之间异同的最佳方式。


一个涉及多个变量的除法问题。为了表示所有这些变量之间的关系，我们使用称为向量的线性量和称为矩阵的数字数组，而不是单个数字。现在我们使用了线性代数的工具，并将数字的概念扩展到了向量和矩阵。


探索新的数系具有经验性。数学家经常注意到，当一个较新的数系遵循与众所周知的旧数系相似的规则时，就会发现这一点。例如，自然数遵循所谓的算术基本定理，该定理指出，所有大于 1 的整数都可以唯一地表示为素数的乘积。对于任何一个数，它总是可以分解成一组素数：例如，42 = 2 × 3 × 7，100 = 2 × 2 × 5 × 5，等等。在研究称为多项式的表达式（多项式包含多个变量，每个变量的幂次不同）时，数学家观察到，与数字一样，一些较大的多项式也可以分解成较小的多项式。例如，多项式 x² + 5x + 4 有两个因式：(x + 4) 和 (x + 1)。这些因子是不可约的，这意味着它们不能分解成更小的多项式，就像质数不能分解成更小的数一样。

人们意识到每个多项式都只能以一种方式分解成不可约多项式。换句话说，他们发现**算术基本定理也适用于多项式**！利用这种紧密的对应关系，数论学家得以在多项式数系中证明新的结论，而多项式数系通常比整数数系更容易处理。


**数学训练的一个重要部分是熟悉不同的概念，并认识到它们之间的关联。这种理解已经融入到我们的符号体系中。我们用同一个加号来表示整数加法、实数加法、复数加法、矩阵加法和多项式加法并非偶然，因为我们已经理解了所有这些运算中共同的抽象加法特征。**


观察平方数——1、4、9、16、25等等——你会发现它们越来越稀疏，彼此之间的间隔以某种均匀的速度增加。这种简单的模式使得回答关于平方数的问题变得容易。


质数似乎还存在一种反模式。质数序列中既有大的间隔，也有小的间隔，看起来似乎是随机的。


十八世纪末，一位名叫卡尔·弗里德里希·高斯的少年痴迷于素数，他开始编纂一张庞大的素数表。他将数据绘制成图表，并推导出一个近似计算小于某个特定数的素数个数的方法。他发现小于 x 的素数个数约为 x / log(x)。后来，这一关系被证明为**素数定理**，该定理指出，当 x 趋于无穷大时，小于 x 的素数个数趋近于 x / log(x)。低于这个极限值时，预测的素数个数与实际素数个数之间的差距会随着 x 的不同取值而波动，这种波动看起来很像随机噪声。

我们用于保护互联网交易和信用卡消费的加密程序，会利用质数的表观随机性，通过算法对数据进行加密。


数论是一个极其庞大的学科，以至于不同子领域的专家可能都无法完全理解彼此的工作。

### 代数

代数学的起源至少可以追溯到3500年前的古巴比伦人，但其名称——以及求解线性方程和二次方程的系统方法——却来自伊斯兰世界。公元830年，花剌子模（al-Khwārizmī，其名字启发了“算法”一词）最初将其称为“al-jabr”，这个阿拉伯语词汇的意思是“修复破碎的部分”。

为了用代数解决问题，我们首先要找出关键的未知数并给它们命名。为了保持名称简洁，我们使用诸如 x、y 和 z 之类的符号。我们倾向于选择不常用且含义中性的字母，以帮助我们进行概括和建立新的联系。

**代数的精妙之处恰恰在于它让我们不必为每个表达式都赋予具体的解释。**


原则上，代数允许我们抽象出任何事物。这正是它强大的关键所在。它的益处是间接的。


代数思维赋予我们灵活运用各种方法解决问题的能力。几年前，我需要在家里安装一些厚重的窗帘，但我不太明白各个部件是如何组装在一起的。站在凳子上拧螺丝对我来说实在太费劲了。不过，从解决代数问题中我们能学到的一点是，要先从简化的特殊情况入手，然后再逐步添加细节。如果你遇到一个涉及变量 x、y 和 z 的问题，你可以先令 x 等于零，这样所有与 x 相关的项就都消失了。然后，你可以尝试在 y 等于零的情况下求解。一旦你更好地掌握了这些特殊情况，就可以将它们结合起来解决一般情况。为了安装窗帘，我先坐在地板上练习把窗帘挂到窗帘杆上。然后我把窗帘杆取下来，试着在没有挂上厚重窗帘的情况下把它挂到墙上。只有在我能分别完成这两个步骤之后，我才尝试整体安装。我妻子取笑我没有一次性完成，但我认为把任务分解成几个部分，并采取有条不紊的方法更有信心。（组装家具显然不是我的强项。）代数教导我们，在着手解决整个问题之前，要先从问题的简化版本中提取关键特征。

代数思维可以克服我们想要记住过多问题细节的倾向。如果我们引入过多的变量，它们会分散我们的注意力，使我们忽略真正重要的信息。更重要的是，它们会模糊我们的视野。即使我们能够解决当前的问题，额外的变量也会阻碍我们发现普遍规律或潜在原理。


与人们对代数的常见误解相反，代数并非机械地照搬公式，而是解决问题。正确运用代数可以揭示计算结果成立或数学关系成立的根本原因。



德国天文学家约翰内斯·开普勒的一个著名故事很好地诠释了这一点。1613年，开普勒在奥地利为他的第二次婚礼购买了一桶葡萄酒。他质疑酒商测量酒桶容量的方法。酒商将酒桶侧放，用一根带凹槽的木棍从桶身中间凸起的塞孔斜插入，一直插到最远的角落，就这么宣布了开普勒需要支付的价格。这些奥地利酿酒商怎么可能仅凭这根木棍就知道酒桶的容量呢？他们肯定有一张表格，上面列出了特定对角线长度对应的酒桶容量。但是，这种表格又如何解释不同形状的酒桶呢？开普勒知道，细长的枪管和粗短的枪管的对角线长度可能相同，但体积却大相径庭。

于是开普勒开始进行代数运算。他计算出，为了在特定对角线长度下最大化酒液量，酒桶的形状必须尽可能接近球形。他发现，与他熟悉的德国酒桶不同，奥地利酒桶的形状与他计算出的最佳形状非常吻合。他的代数运算进一步表明，这些手工酒桶形状的微小变化不会影响用木棍测量酒液量的方法，因为**在给定对角线长度下，酒桶的体积随高度的变化曲线呈抛物线形，并且在接近峰值体积时变化不大**。最终，他证明了酒商的测量方法是准确的，并且理解了这种方法的原理。更重要的是，开普勒运用严谨的代数思维研究酒桶形状，发明了**微积分**的雏形。


说到学习和充分利用代数，我的建议是拥抱抽象。虽然一开始可能会让人望而生畏，但这是数学家拥有的、大多数其他职业所不具备的优势。在科学、医学、工程和社会科学领域，你必须面对现实。（例如，你肯定不希望你的心脏外科医生跟你进行抽象的思考。）但在数学中，你可以随心所欲地改变问题，这不仅能让你探索新的策略，还能让你自由地犯错。数学中蕴含着一种探索的乐趣，而这种乐趣却被我们现有的教学方式所掩盖。数学家在未知领域中工作，然而学校却将这门学科呈现为一系列成功的公式和算法。我们发表的论文都是那些成功的证明。很少有人讨论那些失败的想法，以及最终促成成功的创造性探索。

在函数的世界里，最简单的函数是线性函数。但实际上，生活中几乎所有有趣的事物都是非线性的，因此我们依赖非线性函数来模拟现实世界。有些非线性函数看起来似乎无害，但它们可能会迅速失控。


事实上，科学计算正是利用线性代数来建模那些在局部层面上看似线性的非线性系统，而且效果出奇地好。但是，当被建模的对象比预期更非线性时，这种方法就不一定奏效了。因此，神经网络中的线性运算与非线性函数相结合，以更好地捕捉整个系统的复杂性。然而，事实证明，机器学习中使用的非线性函数与数学家们常用的经典非线性函数并不完全相同，因此机器学习的理论与实践相比还不够成熟。这正是数学需要迎头赶上的一个领域。

如今，我们认为函数是指任何将输入转化为输出的事物。


**在代数领域，抽象的程度是无限的。** 除了将输入转换为输出的变换之外，还有将变换转换为其他变换的运算符。以反演为例。假设你有一个函数，可以将一个几何图形转换为该图形的面积。它以一个图形为输入，并返回一个数值。你可以反转这个函数，使其以一个数值为输入，并告诉你哪些图形具有该面积。

范畴论领域正是现代对这一目标的一次尝试。范畴论是一个统一的概念，它将代数、几何、拓扑、微积分以及其他数学领域联系起来，通过追踪各种变换（甚至包括变换之间的变换）的所有代数性质来实现这一目标。范畴的层级不断递增，从1范畴到2范畴，直至无穷范畴。这听起来或许有些荒谬，但它却是研究数学中深层组织原则的有效语言。


我喜欢用学习数学来比喻清晨薄雾笼罩下的山峦景色。起初，你只能看到山顶，其他的一切都被雾气笼罩。有一座小小的数字山，一座代数山，一座几何山，等等。你学习的是许多独立的知识点。随着学习的深入——随着时间的推移——雾气逐渐散去，你开始看到之前未曾察觉的联系。代数和几何在代数几何的山谷中交汇，你的视野也开始更加开阔，一切都汇聚成一条宽广的河床，如同范畴论一般。

波兰数学家斯特凡·巴拿赫所说：“优秀的数学家能够看到定理或理论之间的类比；而最杰出的数学家则能看到类比之间的类比。” 你在数学学习中走得越远，就越会发现它以意想不到的方式相互统一。



### 几何


几何学在希腊语中意为“测量地球”，但它的起源早于古希腊。巴比伦泥板上记载着如何建造直角物体，以及如何运用几何计算预测日食和月食。早在毕达哥拉斯正式证明毕达哥拉斯定理之前，古巴比伦人和埃及人就已经开始运用这一定理了。希腊人，尤其是欧几里得，对几何学的贡献在于，他们将几何学系统地组织成一组基本公理的逻辑推论。

欧几里得建立了一套系统的方法，用以证明他和其他希腊数学家所掌握的关于几何学和其他数学领域的大部分知识，并将这些知识阐述在他的巨著《几何原本》中。他提出了五条公设（或称公理），作为我们现在所称的欧几里得几何的基础——欧几里得几何是研究平面或三维空间中点、线、角和形状的几何。从这五条公设出发，你可以推导出例如三角形内角和始终等于180度的原因。或者，如果你有一条线段，如何通过画两个圆来求出对应等边三角形的另外两条边。这并非一份需要记忆的事实清单，也不是测量——而是证明。

欧几里得揭示了形状之间抽象关系的丰富内涵。他将线段延伸至任意长度，并定义了全等和相似这两个基本概念——即形状完全相同，或形状相同但大小不同。通过这些努力，他赋予了几何学间接测量那些无法直接测量的事物的能力。

在接下来的几十年里，希腊天文学家萨摩斯的阿里斯塔克斯运用欧几里得的几何论证来估算地球到太阳的距离。由于他无法直接测量地球到太阳的距离，所以他采用了间接方法，即通过地球到月球的距离来估算。他从一个观察到的事实出发：月球绕地球运行时，我们会看到不同的月相。当太阳照亮月球整个可见面时，我们称之为满月；当太阳只照亮月球可见面的一半时，我们称之为半月。他明白，月相的变化取决于太阳、地球和月球彼此之间的相对位置。


阿里斯塔克斯认为，我们看到半月是因为太阳、地球和月球构成了一个直角三角形，直角位于月球的顶点。通过观察半月期间太阳和月球的位置，他估计地球顶点的角度约为87度。由于当时三角函数尚未出现，他只能依靠欧几里得几何来计算太阳到地球的距离大约是月球到地球距离的18到20倍。他的计算结果与实际距离相差约20倍，但关键在于，他基于一个假设：**地球上可测量的三角形几何形状也适用于天体之间巨大的三角形**。基于这个假设，他不仅能够根据月球的距离粗略估算出太阳到地球的距离，还能计算出太阳、地球和月球的相对大小。这使他提出了地球绕太阳公转而非太阳绕地球公转的观点。欧几里得几何帮助阿里斯塔克斯迈出了构建更精确的宇宙模型的第一步。

阿里斯塔克斯认为几何定律适用于他感兴趣的所有尺度，因为欧几里得几何就是这样假设的。这的确是一个巧妙的推断，但并非总是有效。要理解这个问题，我们可以想象地球表面上的一个三角形。在我们人类的尺度下，地球看起来是平的。在平面上，欧几里得几何告诉我们，三角形的三个内角之和始终为180度，勾股定理适用于所有直角三角形。对于浴室地板上的三角形瓷砖来说，情况当然如此。但是，当尺度足够大时，地球的曲率会变得更加明显，这些规律就不再成立了。

以明尼阿波利斯、堪萨斯城和圣路易斯三座城市构成的直角三角形为例。假设堪萨斯城的直角确实是90度。你可以测量以固定速度从明尼阿波利斯飞往堪萨斯城以及从堪萨斯城飞往圣路易斯所需的时间。但是，你不能用勾股定理——对于直角三角形，斜边的平方等于两条直角边的平方和——来计算从明尼阿波利斯飞往圣路易斯所需的时间。而且，如果你测量这三条航线之间的夹角，它们的总和会超过180度。

解开这个矛盾的关键就隐藏在欧几里得五大公设中的最后一个——它隐藏得如此之深，以至于数学家们花了整整两千年才彻底打开非欧几何的大门。欧几里得几何的五大公设中，有四条是显而易见的：两点之间可以画一条直线；直线可以无限延长；圆由一个点和一条半径定义；所有直角都相等。这四条公设都毫无争议。但接下来是欧几里得的第五条公设，即**平行公设**。

平行公理假定，如果一条直线与另外两条直线相交于同一侧，且该侧内角和小于180度，则这两条直线必在原直线的同一侧相交。这条公理听起来如此复杂，与其他四条公理截然不同，以至于连欧几里得也很少提及它。几个世纪以来，数学家们一直试图推翻它。他们想要证明，平行公理是其他公理的推论，但它本身并非几何学的基本公理。

许多思想家尝试过，但都失败了。平行公设虽然看似奇怪，却是证明欧几里得几何所有重要定理（包括勾股定理，其推导过程优美却并非显而易见）的关键。幸运的是，从公元前五世纪的希腊哲学家普罗克洛斯到公元前十八世纪的苏格兰牧师约翰·普莱费尔，数学家们提出了一种更简洁、更易懂的方式来表述这个公设：**当已知一条直线和一个不在直线上的点时，存在唯一一条经过该点且平行于原直线的直线。**

将平行公理降格为定理的努力似乎彻底失败了。但是，正如数学中经常发生的那样，失败——即使是几个世纪以来反复出现的失败——也能带来新的发现。到了十七世纪末，一种不同的策略出现了。一些数学家不再试图直接证明平行公理依赖于其他四个公理，而是转向反证法，试图找出它的致命弱点。他们假设平行公理是错误的，并努力寻找证明它正确的矛盾，看看这样的矛盾会揭示什么。这些探索将他们引向了奇特的新领域：在这些领域中，不存在平行线，或者存在多条平行线经过参考线上的一个点。他们的工作并没有得出矛盾，而是引出了一种不同的几何学。

其中一种类型是球面几何，在这种几何中，形状存在于球体表面。这种非欧几何打破了平行线假设，因为球面上不存在平行线。地球的纬线（表示你位于南北方向的距离）看起来是平行的，但除了赤道之外，没有一条是直线。只有像赤道这样的大圆——其半径等于球体的半径——在球面几何中才是直线。你可以驾驶飞机沿着赤道直线飞行；沿着其他纬线飞行时，你必须不断转弯才能保持航线。（这就是为什么飞机不会沿着纽约市和伊斯坦布尔之间的纬线飞行。这也解释了为什么，正如我们之前看到的，勾股定理在恰好构成直角三角形的城市之间不适用。）

在这些探索过程中，人们也发现了**双曲几何**。球面几何具有正曲率，所有直线都汇聚于一点；而**双曲几何具有负曲率**，所有平行线都发散于一点。事实上，存在无穷多条平行于给定直线且经过该直线之外的点的直线。双曲几何难以想象——试着想象一下生活在马鞍表面而不是球面上。

年轻的匈牙利数学家亚诺什·博雅伊（János Bolyai）在尝试新的曲面几何时，写信给他的父亲法卡什·博雅伊（Farkas Bolyai，一位杰出的几何学家，也是高斯的朋友和同时代人）：“我发现了一些如此奇妙的事情，令我惊叹不已……我从无到有地创造了一个奇特的新世界。”

**高斯**在理解这些新的曲面几何方面发挥了举足轻重的作用。他最伟大的发现之一出现在1827年，当时他**发展出了一套能够从内在角度思考曲率的数学方法**。在此之前，几何特征的研究总是从外部视角出发，即从研究对象之外的角度出发。例如，你可以想象地球表面位于三维真空空间中。然后你可以问，这个表面是平坦的还是弯曲的？这就是我们通常所说的曲率，它是相对于一个外部的、通常是更高维度的平面物体而言的。

高斯的洞见在于他始终关注表面，而从未将表面视为更大空间的一部分。他提出的几何形状可以拥有曲率等非平凡特征——且独立于任何外部环境——这一观点彻底改变了该领域。它催生了研究更复杂曲面和形状的方法，加深了我们对形状本质的理解，并**为微分几何等子领域铺平了道路**（微分几何是爱因斯坦在其广义相对论中使用的数学语言，该理论将引力重新定义为弯曲的时空）。高斯一生证明了许多重要的理论，但他尤其为这一理论感到自豪，他称之为“非凡定理”。

康德和其他早期现代哲学家曾试图将欧几里得几何奉为一种特殊的真理，认为它可以通过纯粹的理性——无需任何观察——来获得。但该领域的发展并非源于早期对单一“真理”几何的执着。正如不存在唯一的真理数系一样，我们现在对几何也有着多元化的理解。最初的非欧几里得曲面几何是连续的、低维的，但现代数学家们已经开始研究离散的、高维的几何。通过同时研究所有这些几何，我们发现，我们对一种几何所建立的直觉往往可以迁移到其他几何上。

如果没有不同几何学之间的思想交流，我们就不会拥有快速可靠的电信、先进的计算机图形学或机器人技术，也不会有现代物理学的许多成就。例如，数字数据传输依赖于欧几里得几何的思想，这些思想被引入到离散的高维空间中。以欧几里得几何中的经典球体堆积问题为例。这个问题源于开普勒在1611年提出的一个疑问：如何在三维空间中以最有效的方式堆积球体？开普勒推测，堆积球体的最有效方式与市场上堆放橙子的标准方式相同，但他无法证明这一点。在近四百年的时间里，其他人也未能证明这一点，直到托马斯·黑尔斯出现并证明了开普勒的猜想是正确的。


开普勒猜想引发了其他关于球体堆积的问题。一些数学家致力于寻找在三维以上维度中堆积球体的最有效方法。另一些数学家则研究了离散空间中的球体堆积问题。正如我们使用笛卡尔坐标 (x, y, z) 来参数化欧几里得几何中的点一样，我们也可以使用 0 和 1 来参数化离散几何中的点。这在计算机科学中尤为重要，因为将数据字符串视为高维空间中的向量有助于理解数据。

在由0和1构成的离散数字空间中，你可以想象出一个个“球”，它们由一个中心0和1组成的字符串以及所有位于该中心一定“半径”内的字符串构成。假设你以一个五位二进制字符串00010为中心，构建一个半径为1的“球体”。那么，这个球体就包含了00010以及所有其他仅相差一位的五位二进制字符串：00110、10010、0000、00011等等。这种球体被称为汉明球，以美国数学家理查德·汉明的名字命名。现在想象一下，一个以一千位二进制字符串为中心、半径为2的数字信息球体。那么你可能会问，在一千维空间中，如何以最有效的方式将这些汉明球打包在一起呢？尽管这样的场景可能看起来令人费解，但这种离散的高维球体堆积问题是开普勒猜想的遥远回响。

事实证明，经典球体堆积的一些数学原理可以推广到数字球体堆积这种截然不同的几何结构中。这在信号处理中非常有用，尤其是在成千上万人同时在同一空间通话的情况下。第一代手机使用模拟信号，容易受到干扰，有时甚至会接到其他人的来电。这促使人们转向发送由0和1组成的数字信号。通过合适的编码，并借鉴欧几里得球体堆积的原理，现在可以在最大限度地减少干扰的同时，最大限度地提高同一频谱的使用人数。
